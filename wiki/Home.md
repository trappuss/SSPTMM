# SSPTMM - Steamified SPT Mod Manager

SSPTMM is a Windows app for finding, installing and keeping track of
[SPT](https://sp-tarkov.com) (Single Player Tarkov) mods. It looks and works like Steam's Workshop.
Mods and collections come from [sp-mod.com](https://sp-mod.com); nothing needs an account or an API
key.

![Browse](https://raw.githubusercontent.com/trappuss/SSPTMM/main/docs/images/03c-browse-hover.png)

## Where to start

1. [Installing](Installing) - download, unzip, run.
2. [First start](First-Start) - point it at your SPT folder and subscribe to your first mod.

## The pages

| Page | What it is for |
|---|---|
| [Play](Play) | Start the server and the game, read the server log, open your mods' tools. |
| [Workshop](Workshop) | Home, Browse, item pages, authors - finding mods. |
| [Subscribing and downloads](Subscribing-and-Downloads) | What happens when you press Subscribe, the downloads bar, Download only, Install from file. |
| [Subscribed items](Subscribed-Items) | Everything in your SPT install: update, enable, disable, pin, group, unsubscribe. |
| [Collections](Collections) | sp-mod.com's public collections, your own, and sharing them. |
| [Tools](Tools) | Configs, Dependencies and Conflicts, Diagnose logs, Mod footprint, Server map. |
| [Diagnose logs](Diagnose-Logs) | What went wrong in SPT's logs, and which mod it came from. |

| [Help and About](Help-and-About) | The built-in Help (F1) and the About page. |

Also: [Safety and backups](Safety-and-Backups) - what SSPTMM does to keep your install and profiles
safe - [Troubleshooting](Troubleshooting), and [Files and network](Files-and-Network) - every
file SSPTMM writes and every server it talks to.

## Names you will see

SSPTMM uses Steam's words for what it does:

| Steam's word | Means |
|---|---|
| **Subscribe** | Install |
| **Unsubscribe** | Remove |
| **Subscribed items** | The mods installed in your SPT folder |
| **Collections** | Mod lists |
