# SSPTMM branding

All of SSPTMM's art in one place, ready to upload: sp-mod.com, GitHub, Discord, anywhere else.
Every file here is generated from the mascot by `build/branding/make_branding.py`. To change the
art, replace `assets/ssptmm-mascot.png` and run the script; don't edit these files by hand.

| File | Size | Use it for |
|---|---|---|
| `ssptmm-thumbnail-512.png` | 512x512 | **sp-mod.com mod thumbnail**: the mascot with the name under it |
| `icon/ssptmm-icon-512.png` | 512x512 | A square icon without text, e.g. a Discord server icon, or the thumbnail if you'd rather have no text |
| `icon/ssptmm-icon-16.png` ... `-1024.png` | 16 to 1024 | The app icon as a PNG. From 16 to 32 px it shows only the head, so it stays readable |
| `ssptmm.ico` | 16 to 256 | The Windows icon, the same one built into SSPTMM.exe |
| `ssptmm-banner-1280x320.png` | 1280x320 | A header for a page or post (the README uses the same banner) |
| `ssptmm-banner-2560x640.png` | 2560x640 | The same header at double size, for high-DPI screens |
| `ssptmm-social-1280x640.png` | 1280x640 | GitHub's social preview, which is set by hand in the repository's Settings > General > Social preview. Also works as a link preview elsewhere |
| `ssptmm-mascot.png` | 426x500 | The mascot alone, on a transparent background |

Links straight to the files, for pasting into a description:

```
https://raw.githubusercontent.com/trappuss/SSPTMM/main/docs/branding/ssptmm-banner-1280x320.png
https://raw.githubusercontent.com/trappuss/SSPTMM/main/docs/branding/ssptmm-thumbnail-512.png
```
